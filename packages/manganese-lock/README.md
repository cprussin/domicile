# @domicile-desktop/manganese-lock

Manganese's lock screen: the passphrase field and a bar of what a locked desktop allows.

## Exports

- `@domicile-desktop/manganese-lock/Lock`
- `@domicile-desktop/manganese-lock/LockBar`
- `@domicile-desktop/manganese-lock/useLocked`

`@domicile-desktop/manganese-lock/panda-preset` holds its keyframes. A shell that renders this package adds the preset to its Panda config.
