A finger on a native window reaches it as a touchscreen touch, so apps scroll, select and pinch as they do on any Wayland desktop. An app that reads no touch gets the first finger as the pointer and its left button. A finger on a window no longer pans or zooms the shell around it. A touchscreen with no `input.pointers` entry now covers the only display when there is one, so a laptop's own touchscreen works with no config.
