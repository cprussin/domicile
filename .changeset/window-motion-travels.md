Send a window flying into its workspace's chip in the bar, grow a client's dialog out of the window it is for, and land a dropped window on a spring. The window model remembers the window each client window is a dialog for (`opener`), and the workspace switcher marks each chip with `WORKSPACE_CHIP`.
