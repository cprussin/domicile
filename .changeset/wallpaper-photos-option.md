The wallpaper rotation has 226 dark and 422 light photos, each checked for resolution, license and brightness, shown in a fresh random order each time through. `runManganese({ wallpapers: { dark, light } })` sets each theme's photos: web addresses, image files and folders of images. `DEFAULT_WALLPAPERS` and `commonsPhoto` help build the list.
