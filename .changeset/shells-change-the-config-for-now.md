A shell makes temporary changes to the config with `domicile.config` (`setOverride`, `resetOverrides`, `overrides`), over the engine's new `changeConfig` and `configoverrides`. Each change says what the file has under it (`written`). An extension's site and file access are set in every browser profile, and one the user installs starts off in every profile, for the shell to ask where it goes on.
