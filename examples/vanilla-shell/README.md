# vanilla-shell

The shell from [SHELL-QUICKSTART.md](/docs/SHELL-QUICKSTART.md) in plain
JavaScript: every window side by side, the focused one outlined. `shell.js` is
the whole shell. [`react-shell`](/examples/react-shell) is the same shell in
React.

```sh
domicile ./shell.js
```

It imports nothing, so Domicile runs it as it is.
