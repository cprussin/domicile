# react-shell

The shell from [SHELL-QUICKSTART.md](/docs/SHELL-QUICKSTART.md): every window
side by side, the focused one outlined, in React. `shell.tsx` is the whole
shell.

```sh
domicile ./shell.tsx
```

Domicile builds it, with `@domicile-desktop/*` and React from its own install,
so it needs no project. `packages/domicile-builder`'s tests build it.
