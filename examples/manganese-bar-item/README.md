# manganese-bar-item

Manganese with one bar item of your own: the time in Tokyo, beside the clock.
The manganese homepage shows it.

```sh
domicile ./domicile.tsx
```

To keep it, use `domicile.tsx` and `tokyo.css` as your
[config module](/docs/use/CONFIGURE.md#a-config-module), in place of
`~/.config/domicile/domicile.json`.

`packages/domicile-builder`'s tests build it.
